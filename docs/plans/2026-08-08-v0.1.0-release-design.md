# v0.1.0 Release Surface Design

Date: 2026-08-08. Status: approved.

## Decisions

- Full customer-facing polish (approach 3): README, CONTRIBUTING, CHANGELOG, example, Makefile, golangci-lint, Dependabot, CODEOWNERS, issue templates.
- Drop internal `docs/phase*.md` from the public tree (not useful to consumers).
- Tag-driven GitHub Releases on `v*` (no Goreleaser).
- Lower module Go version to **1.22**.

## Layout

| Path | Role |
|---|---|
| `README.md` | Install, quickstart, badges, links |
| `CHANGELOG.md` | Keep a Changelog; `[0.1.0]` |
| `CONTRIBUTING.md` | Dev/PR/release process |
| `examples/basic/` | Runnable sketch |
| `.github/workflows/ci.yml` | test/vet/lint on PR + main |
| `.github/workflows/release.yml` | GitHub Release on `v*` tags |
| `Makefile`, `.golangci.yml` | Local + CI entrypoints |
| `.github/dependabot.yml`, `CODEOWNERS`, issue templates | Repo hygiene |

## Release cut

1. Land work on `main`.
2. Tag `v0.1.0` and push.
3. Release workflow publishes notes; pkg.go.dev indexes after proxy fetch.
