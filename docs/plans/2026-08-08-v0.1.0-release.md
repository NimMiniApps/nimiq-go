# v0.1.0 Release Surface Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Make `nimiq-go` merge-ready for main with customer docs, CI, tooling, and a tag-driven `v0.1.0` release path.

**Architecture:** Pure Go module publish (no binaries). CI runs test/vet/lint; tags named `v*` create GitHub Releases from CHANGELOG. Customer docs live at the root; internal phase notes are removed.

**Tech Stack:** Go 1.22+, GitHub Actions, golangci-lint, Dependabot.

---

**Files:**

- Modify: `compat_test.go` (remove phase-doc comment reference)

**Steps:** Set `go 1.22`, delete phase docs, `go test ./...`, commit.
